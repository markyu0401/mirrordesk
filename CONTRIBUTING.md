# Contributing

## Branching

- `main` is protected; all changes go through PRs.
- Feature branches: `feat/<scope>`, `fix/<scope>`, `docs/<scope>`, `chore/<scope>`.

## Commits

Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.

## Pull requests

- One logical change per PR.
- Link the issue (`Closes #123`).
- CI must pass: Android build, macOS build, tests.
- At least one review.

## Issues

Use the templates; include steps to reproduce; logs; device info.

## Releases

Semantic versioning; tags `vX.Y.Z`; GitHub Releases with APK/DMG.
